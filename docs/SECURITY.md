# Security policy

**English** · [简体中文](#安全政策)

If you suspect a vulnerability in Runspur, open an issue titled **Private security contact requested**. Keep the public issue limited to that request. [Open an issue](https://github.com/ohmacemace/runspur/issues/new)

Once a maintainer arranges a private channel, share the Runspur version, the affected client, the impact, and reproduction steps. Remove credentials and private project data before sharing logs or examples.

## 安全政策

[English](#security-policy) · **简体中文**

如果你发现 Runspur 可能存在安全漏洞，请开一个标题为 **Private security contact requested** 的 Issue，正文只写希望私下联系维护者。[新建 Issue](https://github.com/ohmacemace/runspur/issues/new)

等维护者提供私下沟通渠道后，再提交 Runspur 版本、受影响的客户端、影响范围和复现步骤。分享日志或示例前，请移除凭据和私有项目数据。
