# Code of conduct

**English** · [简体中文](#行为准则)

These expectations apply to Runspur issues, pull requests, and other project discussions.

- Welcome contributors of all backgrounds and experience levels.
- Keep feedback specific, respectful, and focused on the work.
- Respect others' privacy. Harassment, threats, discrimination, and sharing someone's private information without consent are grounds for moderation.

Maintainers may remove abusive content, lock discussions, or restrict participation. To report abuse, use GitHub's reporting controls and include a link to the relevant content. [GitHub Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines)

## 行为准则

[English](#code-of-conduct) · **简体中文**

这些准则适用于 Runspur 的 Issue、Pull Request 和其他项目讨论。

- 欢迎不同背景和经验水平的贡献者。
- 就事论事，给出具体、尊重他人的反馈。
- 尊重他人隐私。骚扰、威胁、歧视或擅自公开他人的私人信息都可能受到处理。

维护者可以移除违规内容、锁定讨论或限制参与。举报违规行为时，请使用 GitHub 的举报功能，并附上相关内容的链接。[GitHub 社区准则](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines)
